OpenBSD 8.0 with Xfce on VirtualBox 7.2.22

1. Extract the ZIP into a folder where you want to keep the virtual disk.
   The .vdi file already contains the installed operating system and desktop.
2. Open VirtualBox Manager and create a new VM named OpenBSD Xfce. Choose the
   BSD family and OpenBSD (64-bit). Leave the installer ISO field empty.
3. Allocate 3 GB of RAM and two processors. Use the legacy BIOS (EFI off).
4. Attach the extracted .vdi as the only hard disk on SATA port 0. In the VM's
   Settings > Storage, choose the SATA (AHCI) controller and add an existing
   hard disk. If the wizard attached a blank disk, detach it first.
5. In Settings > Network, select NAT and Intel PRO/1000 MT Desktop (82540EM)
   for Adapter 1. Keep Cable Connected enabled. OpenBSD uses DHCP on em0.
6. For display, start with the VBoxVGA graphics controller, 64 MB of video
   memory, and 3D acceleration off. The guest uses the OpenBSD X display server.
7. Start the VM. Sign in at the graphical login as desktop with the password
   in FIRST-LOGIN.txt. The session opens Xfce.

The image targets Intel/AMD x86-64 computers. The checksum in SHA256SUMS is
for the extracted VDI. The build boots that VDI under QEMU and tests the
graphical login. VirtualBox will first exercise its own virtual hardware when
you start the VM on your computer.
